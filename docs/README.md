# Daftar dokumen

Pegangan kerja yang berlaku ada di akar repo: `README.md` (gambaran dan cara mengembangkan) dan
`RUNBOOK.md` (menjalankan production). Folder ini berisi catatan keputusan yang masih dipakai dan
arsip proses pengerjaan.

## Masih berlaku

| Dokumen | Isi |
|---|---|
| `KEPUTUSAN_PEMILIK_2026-09-23.md` | 21 keputusan yang ditunggu dari pengurus, dengan tempat dampaknya di kode |
| `PANDUAN_ROLE_DAN_UAT_2026-09-20.md` | Panduan per peran dan lembar UAT (butir D2) |
| `OPERASIONAL_DAN_EXPORT_2026-09-20.md` | Aturan export laporan operasional |
| `../DESIGN.md` | Sistem desain: skala bentuk, tipografi, aturan kapital |
| `../PRODUCTION_DEPLOYMENT.md` | Penjelasan aturan: RLS, pengaman skrip database, pembatas laju, header keamanan |
| `../IMPLEMENTATION_STATUS.md` | Riwayat fitur per phase, dengan status terkini di bagian atas |
