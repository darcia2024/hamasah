Keamanan aplikasi

Audit cepat menemukan tiga hal, dan ketiganya sudah diperbaiki.

  • Firewall sederhana terpasang. Permintaan rusak dan penyisiran otomatis ditolak sebelum menyentuh database.
  • Alamat rusak tidak lagi menggantung. Sebelumnya permintaan seperti ini tidak pernah dijawab server.
  • Percobaan PIN pratinjau dibatasi. Menebak PIN berulang kali kini berhenti setelah batas tertentu.
  • Satu komponen pihak ketiga diperbarui. Pemeriksaan dependensi kini tidak menemukan kerentanan.

Seluruh 402 tes otomatis lulus. Ini audit cepat, bukan uji penetrasi penuh.

Yang masih perlu ditindaklanjuti

  1. Konfirmasi bobot rapor

    Dokumen baru mengatur skala nilai. Rapor belum bisa terbit sampai admin memeriksa bobot penilaian di tab Pengaturan.

  2. Akun Tim Media

    Dokumentasi kegiatan umum menjadi wewenang Tim Media, tetapi perannya belum ada di aplikasi. Galeri umum sementara masih dikelola admin.

  3. Catatan persetujuan foto

    Musyrif tetap wajib mengisi catatan persetujuan wali saat menayangkan foto. Dokumen tidak menyebutnya, jadi perlu dipastikan tetap dipakai.

  4. Pengiriman ulang notifikasi

    Tugas terjadwal di GitHub masih gagal, kemungkinan karena pengaturannya belum diisi. Perlu diisi, atau dimatikan bila belum dipakai.
